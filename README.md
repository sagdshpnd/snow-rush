# ❄️ Snow Surfer

An endless snowboarding mini-game built using **Godot Engine (v4.x)** and **GDScript**.  
Inspired by the Microsoft Edge Surf game — this project demonstrates procedural gameplay, player control, enemy spawning, and a full game loop with UI.

## 🎮 Features

- Player-controlled snowboarder with boost and directional input
- Procedural spawning of obstacles and enemies (Yeti)
- Boost pickup and player state transitions (ALIVE, HURT, DEAD)
- Lives system, HUD display, game over logic
- Light animation and screen shake feedback for polish

## 🛠️ Built With

- Godot Engine 4.x  
- GDScript  
- Custom 2D game architecture using Godot scene system
